# Landing Page

Ini adalah landing page statis untuk proyek **Web GIS App**.
Dibuat terpisah dari repositori aplikasi utama agar memudahkan maintenance dan deployment.

## Cara Menggunakan:
1. Ganti link `https://your-flask-app.render.com` di `index.html` dengan URL aplikasi Flask Anda setelah di-deploy.
2. Anda bisa men-deploy folder ini secara GRATIS di:
   - **Vercel**
   - **Netlify**
   - **GitHub Pages**

## Fitur:
- Desain Dark Mode Premium.
- Responsif (Aman dibuka di HP).
- Animasi Bento Grid.
- Hero image futuristik.
